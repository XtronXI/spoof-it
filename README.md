# spoof-it

Launch a dummy Linux executable that Discord detects as a game you are playing.

Discord identifies games by the executable names of running processes. This script looks the game up by title in Discord's own detectable-games database, builds a tiny ELF with the matching name, and runs it.

## Usage

```bash
# Game title (quotes are optional)
./spoof-it.sh "Counter-Strike 2"
./spoof-it.sh Counter-Strike 2

# Nicknames and acronyms
./spoof-it.sh cs2
./spoof-it.sh tf2
./spoof-it.sh gmod

# Browse matching games
./spoof-it.sh --list counter

# Use a custom executable path
./spoof-it.sh --exe <path>

# Preview without building or launching
./spoof-it.sh --dry-run Factorio
```

Run `./spoof-it.sh --help` for all options.

## Updating the game database

```bash
./spoof-it.sh --update-db
```

Downloads the latest game list. Add `--dry-run` to check without writing.

## How it works

The script matches the title against Discord's detectable-games list stored in `detectable.json`. It prefers the Linux executable name (falling back to the
Windows name, which is what Discord sees for Proton/Wine), compiles a tiny dummy at that path under `/tmp`, and starts it detached. Re-running for the same path stops the previous dummy first.

`detectable.json` is generated by `--update-db` and contains only what the script needs to match games and choose an executable.

Some games have no executable entry. For those, the dummy is named after the game title under a fake Steam-like path such as `/tmp/spoof-it-steam/steamapps/common/EA Sports FC 27/EA Sports FC 27.exe`. Discord's own process observer can resolve that by name. That can also count toward Discord quests, because quest progress uses the same name lookup. This is not an injection and does not modify Discord.

With `--exe`, no game lookup happens: the exact path you give is used for the dummy.

## Notes

- Linux with bash is assumed; the dummy is a Linux ELF.
- `python3` is required. `gcc` is required to build and launch the dummy. The
  wrapper checks both and offers to install them.
- Discord must already be running.
- `--exe` uses the exact path you provide; the parent directory must be
  writable.
- Name-only spoofing relies on Discord's own name matching. Discord may count
  it as playtime for quests; use it only if you accept Discord's ToS.
